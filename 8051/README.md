## Overview

This directory contains the 8051 microcontroller laboratory experiments performed as part of the Foundations of IoT Laboratory.

The experiments focus on Embedded C programming, GPIO configuration, LED interfacing, push-button interfacing, LCD interfacing, keypad interfacing, timer operations, and UART serial communication.

The programs are developed using Keil µVision and the Keil C51 compiler.

**Hardware:**
- 8051 Microcontroller (AT89S52)

- Keil µVision
- Keil C51 Compiler
- Embedded C
- PuTTY (Serial Communication)

## Project Files

A typical 8051 task folder contains:

```text
TASK/
├── main.c
├── TASK.uvproj
├── TASK.uvopt
├── Objects/
├── Listings/
├── README.md
└── circuit.png
```

**File Description:**

| File / Folder | Description |
|---|---|
| `main.c` | Embedded C source code |
| `.uvproj` | Keil µVision project configuration |
| `.uvopt` | Keil project options and settings |
| `Objects/` | Compiled object files and generated output files |
| `Listings/` | Compiler-generated listing files |
| `README.md` | Experiment documentation |
| `circuit.png` | Circuit diagram |

## Objective

To understand the architecture and programming of the 8051 microcontroller, Embedded C programming, GPIO operations, peripheral interfacing, timer configuration, and UART serial communication through practical laboratory experiments.

The experiments provide hands-on experience in developing and testing microcontroller-based embedded systems using the 8051 architecture.
