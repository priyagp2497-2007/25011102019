## 2. Core Logic / Pseudocode / Code Base

### Working Principle

The AT89S52 microcontroller controls the brightness of an LED using Pulse Width Modulation (PWM).

Timer 0 is configured in Mode 2 (8-bit auto-reload mode) to generate periodic interrupts. Inside the Timer 0 interrupt service routine (ISR), a PWM signal is generated by comparing the current tick value with the duty cycle.

The duty cycle determines how long the LED remains ON during each PWM period.

- A higher duty cycle produces greater LED brightness.
- A lower duty cycle produces lower LED brightness.
- A duty cycle of 0 turns the LED OFF.
- A duty cycle of 20 turns the LED ON continuously.

The main program gradually increases the duty cycle and then decreases it, producing a continuous LED fading effect.

### Timer 0 Configuration

Timer 0 is configured using the following registers:

- `TMOD`: Configures Timer 0 in Mode 2.
- `TH0`: Stores the auto-reload value.
- `TL0`: Stores the initial timer value.
- `ET0`: Enables Timer 0 interrupts.
- `EA`: Enables global interrupts.
- `TR0`: Starts Timer 0.

The value `0xD2` is loaded into TH0 and TL0.

For an 11.0592 MHz crystal, assuming the standard 12-clock 8051 timer cycle:

\[
T_{machine}=\frac{12}{11.0592\times10^6}
\]

\[
T_{machine}\approx1.085\ \mu s
\]

The timer counts 46 increments before overflowing:

\[
T_{interrupt}=46\times1.085
\]

\[
T_{interrupt}\approx50\ \mu s
\]

### PWM Generation

PWM stands for Pulse Width Modulation. It controls the average power supplied to the LED by changing the ON time while maintaining a fixed period.

The program uses:

- `PWM_STEPS = 20`: Number of ticks in one PWM period.
- `duty`: Determines the LED ON duration.
- `tick`: Tracks the current PWM position.

The interrupt routine checks:

`LED = (tick < duty);`

If the current tick is less than the duty value, the LED is turned ON. Otherwise, it is turned OFF.

The PWM period is:

\[
T_{PWM}=20\times50\ \mu s
\]

\[
T_{PWM}=1\ ms
\]

Therefore, the PWM frequency is approximately:

\[
f_{PWM}=\frac{1}{1\ ms}=1\ kHz
\]

### LED Brightness Control

The program uses two variables to control the fading direction:

- `dir_up = 1`: Increases the duty cycle.
- `dir_up = 0`: Decreases the duty cycle.

The `fade_flag` indicates when the main program should update the duty cycle.

The duty cycle changes once every 50 PWM periods, which is approximately 50 ms.

The LED gradually fades from minimum to maximum brightness and then fades back to minimum brightness.

### Pseudocode

1. Start the program.
2. Initialize the LED to OFF.
3. Configure Timer 0 in Mode 2 (8-bit auto-reload mode).
4. Load `0xD2` into TH0 and TL0.
5. Enable Timer 0 interrupts.
6. Enable global interrupts.
7. Start Timer 0.
8. Enter an infinite loop.
9. In the Timer 0 interrupt routine:
   - Increment the tick counter.
   - Reset the tick counter after 20 ticks.
   - Increment the PWM period counter.
   - Set the fade flag after 50 PWM periods.
   - Compare the tick value with the duty cycle.
   - Turn the LED ON or OFF accordingly.
10. In the main loop, check the fade flag.
11. If the flag is set:
    - Increase the duty cycle when fading up.
    - Decrease the duty cycle when fading down.
    - Change the fading direction at the minimum or maximum duty cycle.
12. Repeat continuously.

### Code Base

The C program is written using Keil C51 for the AT89S52 microcontroller.

```c
#include <reg52.h>

sbit LED = P1^7;

/* PWM Configuration */
#define PWM_STEPS 20
#define FADE_PERIODS 50

volatile unsigned char duty = 0;
unsigned char tick = 0;
unsigned char period_cnt = 0;

bit fade_flag = 0;
bit dir_up = 1;

/* Timer 0 Interrupt Service Routine */
void Timer0_ISR(void) interrupt 1
{
    tick++;

    if (tick >= PWM_STEPS)
    {
        tick = 0;
        period_cnt++;

        if (period_cnt >= FADE_PERIODS)
        {
            period_cnt = 0;
            fade_flag = 1;
        }
    }

    LED = (tick < duty);
}

/* Main Function */
void main(void)
{
    LED = 0;

    TMOD = (TMOD & 0xF0) | 0x02;

    TH0 = 0xD2;
    TL0 = 0xD2;

    ET0 = 1;
    EA = 1;
    TR0 = 1;

    while (1)
    {
        if (fade_flag)
        {
            fade_flag = 0;

            if (dir_up)
            {
                if (duty < PWM_STEPS)
                    duty++;

                if (duty >= PWM_STEPS)
                    dir_up = 0;
            }
            else
            {
                if (duty > 0)
                    duty--;

                if (duty == 0)
                    dir_up = 1;
            }
        }
    }
}
```

### Code Explanation

- `#include <reg52.h>`: Includes the 8052 microcontroller register definitions.
- `sbit LED = P1^7`: Assigns P1.7 as the LED control pin.
- `PWM_STEPS`: Defines 20 ticks per PWM period.
- `FADE_PERIODS`: Defines 50 PWM periods between duty-cycle updates.
- `duty`: Stores the current PWM duty-cycle value.
- `tick`: Tracks the current position within a PWM period.
- `period_cnt`: Counts the completed PWM periods.
- `fade_flag`: Indicates when the duty cycle should be updated.
- `dir_up`: Determines whether brightness should increase or decrease.
- `Timer0_ISR()`: Handles timer interrupts and generates the PWM signal.
- `TMOD`: Configures Timer 0 in Mode 2.
- `TH0` and `TL0`: Load the timer reload and initial values.
- `ET0`: Enables Timer 0 interrupts.
- `EA`: Enables global interrupts.
- `TR0`: Starts Timer 0.
- `while(1)`: Continuously checks the fade flag and updates the duty cycle.
